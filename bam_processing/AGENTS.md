# `bam-processing`

## Docstrings

Write a docstring for every module, function and class.

Write function docstrings in the format:

```python
def myfunc():
    """
    Here is the description of the function.

    Args:
        arg1 (type):
            Description of arg1.
        arg2 (type):
            Description of arg2.

    Returns:
        type:
            Description of the return value.
    """
    pass
```

Note that a line break is required after `:` and the each line shouldn't exceed
78 characters. Also, note that there is a line between `"""` and the
description.
